## What the learner now sees

- **Learn** opens with "Your learning path" (resume or start), "My Course" (level selector Foundations–C2), the next grammar lesson, a session menu (Together / Grammar / Verbs / Words) and then the vocabulary decks and review pane.
- **My Course** (`#/course`) lists every unit and lesson of the selected stage with Start / Resume / Revisit, a skill profile (grammar, reading, listening, writing, speaking, interaction), earlier course work, and optional expansions for extra verb forms.
- **Grammar lesson** (`#/learn/grammar/:id`): words → teach → guided checks → independent checks (choice, match, order, type) → passage → recap; wrong answers open target-specific repair; pause saves the exact step.
- **Verb lesson** (`#/learn/verb/:id`): a picker of five tenses (Present, Completed past, Past background, Future, Conditional), each a taught chapter with simple forms, progressive usage where appropriate, and a contextual final review. The original 12-scene walkthrough remains behind Me → Adaptive lessons (off).
- **Word lesson**: short Learn → Practise loop (meaning, recall, article, plural, context, listening) with evidence per skill.
- **Review** is driven by demonstrated skills and only draws verb forms from completed cases; the classic SRS runner is used when adaptive lessons are off.

## Observations for the next round

1. `README.md` was not updated: it still describes the 12-scene walkthrough as the learning flow and does not mention the course, the Learn hub changes, the new check suites or the audio cache.
2. The deploy workflow runs the 33 deterministic checks but no browser suite; the 19 browser suites run only on pull requests (`.github/workflows/check.yml`). Direct pushes to `main` therefore skip them.
3. First install now precaches 111 files (about 7 MB with the dictionary and course packs) atomically; audio is on demand. Every shell or course-data change needs a `sw.js` VERSION bump.
4. `docs/` carries 2.1 MB of JSON audit output that is deployed with the site (the Pages artifact is the whole repository).
5. Browser coverage is Chromium (and WebKit for some suites) with phone emulation; no physical iPhone check is recorded.
