## Findings sent to the author

1. **Answer-provided copying is not unaided production.** Sixty-seven of the 72 language typed questions display the exact requested surface answer in English, for example “Use dimostrare”, “Use indipendente” and “Supply a”. Reusing the intermediate compiler would declare them independent production for `requiresProduction:true` targets. These can serve guided/assisted practice; each required production target needs actual unaided retrieval, or a narrower evidence-mode requirement. Giving an infinitive plus a requested person/mood is a different task and can require genuine form production. This remains open until the compiled attempts are inspected and exercised.
2. **Clear interim endpoint.** The comparative-synthesis portfolio used a stative non-negative `finché` clause that could be read as duration rather than waiting for availability. The author changed it to `finché non sarà disponibile un confronto omogeneo`. This is a clarity correction, not a claim that endpoint `finché` always requires `non`: the [Crusca consultation](https://accademiadellacrusca.it/it/consulenza/perch-a-volte-si-mette-la-negazione-dopo-emfinchem-e-altre-questioni-relative-ai-modi-dei-verbi/27376) describes the optional endpoint negation and the separate duration reading. Source correction received; compiled re-review pending.
3. **Determiner and agreement.** Comparative-synthesis question C3 says `Due fonti usano stessi giorni, unità e campione`. It needs explicit determiners and agreement, for example referring to `agli stessi giorni` and using `la stessa unità` and `lo stesso campione`. Correction requested.
4. **Explain the actual model.** The future-perfect conjecture transfer explanation discusses `avrà ricevuto`, while its model contains `avrà letto`. Both are grammatical, but aligning the explanation makes the preparation direct. Correction requested.
5. **Disclose internal literary omission accurately.** The C2 second-preface final source ends a sentence after `ammirarci a vicenda`; the original continues within that sentence. Its changes metadata claims sentence-boundary shortening. Retain the full sentence, explicitly mark the internal omission, or choose a true sentence boundary, and describe the edit accurately. The C1 first-preface modernizes `vizii` to `vizi`, so the changes description should also mention spelling, alongside accents/typography.
6. **Carry attribution into the consumed content.** The advanced reading records retain author, title, stable source URL, license and changes. A compiler copied from the intermediate input path must preserve and expose those fields. This is an integration check to resolve with the actual generated pack/player, not a finding that the unimplemented consumer has already dropped them.

The two authentic literary selections were compared against [Pirandello’s first preface](https://it.wikisource.org/wiki/Il_fu_Mattia_Pascal/1) and [second preface](https://it.wikisource.org/wiki/Il_fu_Mattia_Pascal/2). The pages identify the exact permanent revision IDs named by the records. Apart from the omission disclosure above, the selected wording and keyed interpretations agree with the supplied passages; the metadata identifies editorial modernization. Historical narrative stance is distinguished from a science claim and from contemporary service-language models.
