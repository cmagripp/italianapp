## Input and open practice

Two new Foundations targets use actual source-linked listening: first-contact details and familiar hard/soft c words. A1 adds a calendar reading target, a reading/relay exit and a listening exit for changed arrangements. The player records transcript assistance. Finding a detail in a source is separate from the optional recorded or written portfolio, which is self-review. Stage exit practice samples reception, production, interaction and mediation but does not award assessed open skill competence or certified CEFR proficiency.

The slice uses original fictional text and 24 synthetic practice clips (116.57 seconds, 970105 bytes). The manifest records Kokoro model/voice provenance, Apache2 license URLs, transcript hashes and byte hashes. 24/24 clips currently pass automated Whisper transcription comparison. This is an automated intelligibility check; it is not native-human pronunciation approval or authentic natural dialogue. The existing130 reviewed assets are retained.

The communicative scope follows the [A1 reference syllabus from the four Italian certifying bodies](https://www.unistrapg.it/sites/default/files/docs/certificazioni/sillabo-4-enti-A1.pdf), read for supported everyday interaction, familiar messages and information exchange. No external text is reproduced in the lessons.
