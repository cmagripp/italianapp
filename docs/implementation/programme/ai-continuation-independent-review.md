# Independent saved-conversation continuation review

The metadata bridge uses read-only repository list/read transactions, returns navigation metadata rather than cached transcripts, and closes the repository. It does not acquire a provider, download a model, grade an answer or rewrite conversation/learning records. When the browser inventory proves the conversation database absent, the bridge skips opening it. Where that inventory API is unavailable, the normal repository fallback remains the limitation. Cache identity covers profile, learner and learning epoch; an overlapping request has a separate lease. Real saved work competes by its updated time with the exact saved lesson. Empty, archived and deleted conversations are excluded.

An independent Chromium probe found that the outer Home and Learn renderers could still paint after their delayed inventory work finished. Navigating to Profile first left the route at `#/profile`, but the old renderer replaced Profile's settings with Home/Learn content. The router's post-render generation check ran after the stale DOM write. The historical report is `ai-continuation-audit-chromium.json`.

Root added `captureViewOwnership`: router generation, connected root and captured profile/learner/epoch are checked immediately after optional asynchronous loads, before paint, and around later Learn fills/Home interactions. The independently asserting suite now also covers leaving and returning to the same route while the earlier request remains pending. Only the first, stale inventory request is released after an owner change. Full profile JSON remains unchanged in those cases. The initial historical epoch probe released the latest request instead; its new-owner Home render performed normal today-counter initialization, so that probe did not establish writes by the bridge.

Five metadata/lease Node checks and ten independent browser checks pass in Chromium and WebKit. The browser cases cover navigation, profile replacement, learner replacement, epoch reset and overlapping renders on the same route. `ai-continuation-audit-after-chromium.json` and `ai-continuation-audit-after-webkit.json` retain the fixed outcome. The default `tests/conversation-continuation-independent-e2e.mjs` asserts every case; `--before` is solely for a deliberate historical reproduction.

The same initial-load ownership boundary is now applied to workshop, current Course and retained Grammar hosts. Their identity checks for intentionally saving a stopped portfolio recording after navigation remain separate; that existing durable recording behavior is not cancelled by the new initial-paint guard. Assistance/owner browser regression evidence is retained separately.

No production model readiness or physical iPhone behavior is inferred from this review.
