# Selected conversation study

Implemented `js/conversations/study.js` and the narrow conversation view/summary integration. Conversation notes now open an in-place selection sheet supporting one to sixteen encountered items, explicit sentence selection where an item occurs more than once, answer choices, small matching groups and flashcards. There is no four-item minimum, generic random quiz routing, model call or automatic lesson completion.

Questions are rebuilt from exact current messages and local canonical dictionary/objective records. A uniquely identified finite verb form uses only the encountered tense and person. Ambiguous forms, including person-ambiguous `sono`, use meaning practice instead. An explicit lexical choice for `andata` retains its complete accepted feminine form `sono andata`, including audio. Imported summary glosses, guessed cases and saved question HTML do not become question authority.

An actual graded choice or match invokes an owner/learner/epoch/source-guarded callback and records canonical recognition evidence with `conversation-study` assistance. It carries the exact source turn, revision, word range and quote in its context. It does not award recall, mark words learned, complete lessons or enroll unlearned cases in Review. Exposure, saving, flashcard viewing and restoration emit no assessment event. Stable session/target/attempt IDs deduplicate retry; an existing ID with different source/variant/objective metadata is rejected.

Study UI state lives in the existing conversation summary. Restoration requires the independently rebuilt full plan fingerprint, owner, epoch and exact source versions. Saved outcomes are recomputed against actual canonical choices; matching identities and prior answers are independently validated. Profile evidence saves before study UI persistence. A failed study save after a successful profile save is recoverable: reload and retry reuse the original assessment rather than duplicating or rewriting it. A colliding imported session identity can be discarded through a fresh selection.

Correct feedback plays the canonical question audio/form/word through shared speech controls. Italian matching labels/forms play when tapped. An unverified learner sentence never becomes automatic success audio. The explicit “Hear original” control reads the quoted original after checking its current source. Restoration never autoplays. The audio checks capture shared speech calls; they do not establish audible quality or offline voice availability on an installed physical device.

Browser tests exposed an existing view-listener leak: the reused application root retained conversation click handlers after navigation, opening two active notes sheets. Scoped abortable listeners now stop immediately at view cleanup, while the existing asynchronous controller disposal still gets to flush its pending draft. UI publication and queued actions stop immediately when the view closes. Busy matching persistence disables tiles without switching the shared activity renderer into its answer-revealed presentation.

Validation: ten pure Node study tests, the existing six summary checks, and twelve targeted browser checks in each of Chromium and WebKit pass. The browser cases cover one-item practice, supported evidence, resume, silent restoration, flashcard exposure, tense/person bounds, double activation, matching/audio, quoted-source audio separation, source edits, failed persistence, imported ID collisions and navigation/profile isolation. Reports: `ai-conversation-study-chromium.json` and `ai-conversation-study-webkit.json`. Reproduction: `tests/conversation-study.test.mjs` and `tests/conversation-study-e2e.mjs`. The Node suite is included in deterministic check/deploy workflows; browser study and independent status suites run in both engines in browser CI.

No production conversation provider is enabled. This slice uses explicitly committed test messages and canonical local assessment, independently of the failed model quality trials. Physical iPhone runtime, installed-PWA cold start, human speech quality and model approval remain separate gates.
