# Selected verb scene compatibility

This is an additive presentation contract for resumable verb journeys. It does not change learning schema 6, target IDs, case coverage, readiness, remembered evidence, old events, XP or completed cases.

Every newly selected expanded question stores a bounded `sceneSnapshot` on `journey.current`: entry/target/chapter identity, variant, source revision, pool size, cue mode and the exact selected Italian/English context, person/role and accepted forms. No HTML, executable callbacks or complete question objects are imported. Existing trusted question templates escape and render these fields.

The snapshot is executable only when **every context field and the selection position/pool/cue match the current authored revision or an explicitly declared previous expanded revision**. A changed subject, translation, source, answer, target, variant, revision or pool cannot manufacture a new teaching sentence. Unknown or malformed snapshots remain unavailable and retain their active draft/descriptor. A future source edit must preserve its earlier revision and full selected-context ordering before publication; a snapshot is not independent semantic approval of unregistered text.

A bounded optional `legacyExpandedRevisionAliases` list may name the same explicit full historical pool. The source compiler permits at most eight unique nonempty revision names, distinct from current and canonical prior revisions. Alias snapshots still require exact Italian/English/form/source/order/cue matching; unknown aliases and altered fields remain unavailable. Retirement applies to canonical prior revisions and their declared aliases. Odiare now uses current revision `odiare-neutral-frame-2026-10-03-2`, preserving the actual prior `-1` and its earlier declared prefix alias. Valid old `Odio alzarmi presto` remains resumable; person-invalid prior selections require explicit correction.

Older expanded-v1 sessions without a snapshot pin their active sentence from the explicit previous expanded pool. This is separate from `legacyFrames`/`legacyAuthoredContexts`, which preserve the older non-expanded lesson flow. Question ID, draft, submission, activity state and feedback stay unchanged until Continue. Continue selects a current scene; history/Back retain the exact previous structured scene, including its original cue mode. Existing case cursors retain their own snapshots.

The domandare correction uses `a Sara come sta` for fresh selections. Independent source review classified the earlier `una domanda` model as invalid teaching, so its 49 exact earlier frame-context IDs use the retirement transition rather than continued grading. Retirement is bound to the **previous source revision**, allowing corrected current sentences to retain the same stable IDs. The harmless continuity fixtures use the unchanged valid `una cosa` frame. `legacyExpandedExamples` also supports English-only dictionary-example revisions. Controllare's interrogative `dictionary-1` is currently a teaching/reference example, not a selectable question: the conservative source parser does not infer a grammatical person from English beginning “Did you”. Its active dictionary-0 is used for the controlled translation-revision regression instead.

Semantic-invalid contexts have a different policy. An authored `retiredExpandedContextIds` declaration blocks further grading and opens **“This example has been corrected”**. The learner must choose Continue; the full old journey/UI is retained in `session.sceneCorrectionRecovery`, and a current activity receives a fresh question identity without recording an answer or adding credit. Retained historical evidence/completion is not silently rewritten. This is verified for the four compound-overlap cases (fiorire, peggiorare, sparire, emanare), including ordinary v1 selection, and for all 49 old domandare contexts. If a removed context-only target has no current scene, the transition chooses its available same-person conjugation target rather than inventing a replacement sentence. Fresh form-only questions carry an explicit current revision marker so they cannot be mistaken for old unsnapshotted cursors.

A reload regression also exposed a separate feedback issue: normalized component object key order could rebuild valid saved supported-answer feedback. Component comparison now uses semantic skill/result pairs, preserving the saved receipt text.
